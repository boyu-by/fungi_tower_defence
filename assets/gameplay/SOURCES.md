# 局内美术来源

2026年10月20日接入首批37张PNG，随后从父目录“素材”补充7张小画家与羊群贴图，共44张，均原样复制。原始文件仍位于工程父目录的三章素材文件夹和“素材”文件夹。本批美术按用户交付记录来源，不适用其它免费素材包的CC0声明。

图片中的透明留白通过AtlasTexture资源裁切，未修改原图像素；碎纸机动画与菌结状态使用统一裁切范围。
