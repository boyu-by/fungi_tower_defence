# 音效接入与调整

2026年10月19日接入。三关、主菜单与四段CG共用同一份声音配置，使用本地素材中的18个音频文件，约188 KiB。

## 游玩时的声音

| 事件 | 配置ID | 触发规则 |
| --- | --- | --- |
| 按钮点击 | ui_click | 实际按下可用且可见的按钮；悬停、焦点变化不响 |
| 取消短音 | ui_cancel | 供界面复用的备用短音，当前普通按钮统一用轻点击 |
| 放置生长目标 | place | 生长系统接受新任务后播放，不响应无效预览 |
| 普通/破甲/散射发射 | shoot / shoot_heavy / shoot_scatter | 整轮弹丸实际提交后响一次；散射不按三颗重复播放 |
| 命中 | hit | 弹丸实际造成正伤害后触发，未到达或目标消失不响 |
| 敌人/设施死亡 | death | 真实死亡事件；删除一个存活对象不触发 |
| 新菌结形成 | grow | 真实形成菌结时播放短促生长声 |
| 生长或器官成熟 | built | 任务完成/器官成熟时播放 |
| 营养回流 | income | 唯一产物抵达母核才触发，普通加款或退款不触发 |
| 母核受伤 | core_hit | 生命实际减少时警示，修复不播放 |
| 成长/分化 | stage / evolve | 真实阶段变化或分化完成时触发 |
| 第三关碎片收集 | fragment | 实际收集完成时触发 |
| 胜利/失败 | victory / defeat | 结果发出时播放一次，暂停状态下仍可听见 |
| CG换幕 | paper | 当前画面编号变化时播放；刷新同一幕不重复 |

## 音量与暂停

主菜单右下角、关内暂停菜单和CG底部均有音效音量控件。点击“音效”可以静音，再次点击恢复；滑块范围为0–100%。首次默认70%。

音量单独保存在 `user://audio_settings.cfg`，不改写关卡进度文件。拖动音量后延迟0.4秒保存，退出当前场景时也会保存尚未落盘的设置。

世界声部跟随全局暂停，界面与提示乐句仍可播放。结算停止战斗声后播放胜负提示；重开、切关和返回标题会释放本场景的播放器，避免旧关声音残留。

每个场景固定9个声部：界面2、世界6、提示乐句1。高频事件分别限流与限制同时播放数；世界声部满时，母核警报等较高优先级声音可以替换普通射击。没有给每个弹丸或运输包创建播放器。

## 在编辑器里调整

1. 打开 `resources/audio/sound_bank.tres`，展开 Cues。
2. 按 ID 找到声音，调整 Streams、Volume Db、Pitch Min/Max、Cooldown、Max Voices、Priority 或 Duration Limit。
3. `Volume Db` 越小越轻；普通射击当前约为-27 dB，警报和结算更明显。
   纸笔原素材本身较轻，单独使用-4/-3 dB补偿，不应直接套用射击的衰减量。
4. `Duration Limit` 为0时播完整素材；正值会限制片段，并在结尾40毫秒淡出。
5. 替换声音时先将文件放入 `assets/audio/sfx/`，再修改资源引用与 `assets/audio/SOURCES.md`。

统一总线位于 `default_bus_layout.tres`：UI、World、Stinger 经过 Effects 汇入 Master。音量控件只调整 Effects，总线没有承担玩法逻辑。

## 工程位置

- `scenes/audio/game_audio.tscn`：编辑器中可见的固定播放器、限流配置入口及事件观察器。
- `scripts/audio/game_audio.gd`：片段选择、播放、音量、限流和释放。
- `scripts/audio/colony_audio_feedback.gd`：订阅玩法事实，不扣款、不伤害目标、不推进任务。
- `scripts/audio/ui_audio_feedback.gd`：监听本场景按钮；新出现的按钮也会接入。
- `scenes/audio/audio_volume_control.tscn`：主菜单、暂停菜单和CG复用的音量控件。
- 共用玩法场景包含唯一 GameAudio；独立CG预览在没有场景播放器时创建同一音频场景。

## 验证

`tests/audio_feedback_test.gd` 检查素材可加载、声部与限流、音量保存、真实射击与命中时序、唯一回流、三关接线、暂停、结算和释放。

本次音效定向检查88项通过，另通过剧情、主菜单、共用玩法、命中结算、紧凑HUD、第一关整合、第二关与第三关回归。实际GL窗口检查了主菜单、CG与暂停页布局；使用游戏混音器录制首波战斗和提示音，默认音量下录音无削波。该录音包含独立调用的提示音预览，不是正常通关证据。

音效只提供反馈。自动测试中的直接伤害与产物注入是明确的隔离夹具，不是正常游玩或关卡平衡的证明。
