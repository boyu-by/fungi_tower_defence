主线：标题开始 → CG1初次绘画 → 第一关 → 胜利结算的下一关按钮 → CG2 AI冲击 → 第二关 → 胜利结算的下一关按钮 → CG3成年后的思考 → 第三关 → 冻结展示网络1.5秒 → CG4与自己和解 → 通关结算。

继续游戏从已解锁关卡开头进入，不重复播放开场CG；重开当前关不播放CG。新游戏始终播放CG1。关卡战斗、资源与胜负条件不变。

四份资源位于 `resources/story/cg1.tres` 至 `cg4.tres`。目前未填图片，显示策划原文与剧情标题，按“继续”或Space进入后续流程；Esc和“跳过剧情”走同一个完成入口，不重复切关。

## 替换图片

1. 将图片导入项目，例如 `assets/story/cg1/`。
2. 在Godot检查器打开对应CG资源，在 `frames` 数组依次拖入图片。图片保持比例完整展示，不裁切。
3. `frame_seconds` 为每帧停留秒数，按数组顺序配置。未指定的帧使用 `default_frame_seconds`，默认2秒；最小0.05秒。
4. `title` 和 `caption` 分别控制标题与整段文案。四段可分别调整。

图片默认自动逐帧切换，形成定格动画。可暂停自动播放，点击“下一帧”或Space手动推进；最后一帧停留，点击“继续”才离开，确保能读完文案。支持任意数量图片，暂不包含配音、插值或逐帧字幕。

共用播放逻辑位于 `scripts/story_player.gd`，配置类型位于 `scripts/story_sequence.gd`。播放器使用独立覆盖层，拦截键盘操作和画面点击，战斗冻结时仍能操作。CG1由主线导航管理；CG2、CG3由胜利继续按钮管理；CG4沿用第三关结尾时机。独立运行关卡也能播放后续CG。

当前只保存关卡进度，不保存逐段观看记录；离开后从“继续游戏”进入最新解锁关卡。
