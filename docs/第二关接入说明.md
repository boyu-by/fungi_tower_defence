# 第二关接入说明

## 运行与目标

项目默认仍从现有第一关启动。第一关胜利面板新增“进入第二关”；也可直接运行 `res://scenes/levels/second_level.tscn`。

第二关目标为摧毁左、中、右三台AI，并保持母核存活。设施分别为120、180、240生命，使用稳定ID `left`、`center`、`right`。不要求清空已生成敌人或完成全部建设。母核归零判负，同帧第三台设施摧毁与母核死亡时失败优先。

## 文件与职责

| 文件 | 职责 |
| --- | --- |
| `scenes/levels/second_level.tscn` | 地图、初始组织、尸骸、设施、地形和控制器引用 |
| `scripts/second_level.gd` | 共用系统接线、目标选择、预览、暂停、重开和结算接入 |
| `scripts/ai_facility.gd`、`scenes/combat/ai_facility.tscn` | 固定设施、真实受击、唯一摧毁、占位外观与生产状态 |
| `scripts/ai_production_controller.gd` | 独立持续生产、来源身份、压力上限、摧毁停产和退场清理 |
| `scripts/ai_production_profile.gd`、`resources/ai/second_level_production.tres` | 可编辑生产参数、五类敌人和阶段配比 |
| `scripts/second_level_hud.gd`、`scripts/second_level_guide.gd` | 第二关目标显示、结算和首次敌人提示 |

共用工具坞支持第一关的六波与第二关的设施目标显示。第一关原地图和波次资源继续使用原配置，第二关不继承第一关的六波或演示脚本链。

## 生产与身份

- 初始准备10秒，生产周期10秒；提前开始按钮只结束初始准备一次。
- 早期每台每次生产1个普通敌人；20秒后加入2个小型敌人，30秒后再加入1个重甲和1个专职啃食者。两种啃食者按来源和周期交替，数量与时间均可配置。
- （可在之后按需求在配置文件中更改）
- 小型敌人保留成组出生和组内间隔；每个实际成员独立记数。
- 每次生产创建独立的 `EnemySpawner`，上一批仍存活时也可以创建下一批。每个敌人保留 `source_id`、`batch_id`、`spawn_id`。
- 每来源同时存活及待出生数量上限为18；达到上限时暂缓生产，数量不无限增长，也不要求先清场。
- 摧毁来源取消它所有待出生成员，已出生敌人继续行动。其他设施不增产，下一次生产至少延后20秒。
- 出口避开岩石和已有菌落节点；没有合法落点时暂停该次生产并显示出口受阻。
- 暂停冻结设施周期、组内计时与玩法；恢复不补发暂停期间的批次。退出、重开与终局停止本局生产。

## 设施战斗与五类敌人

AI使用经过适配的 `BasicEnemy` 受击接口，以复用真实弹丸、弹药扣费与在途伤害协调。设施不移动、不攻击、不自动恢复生命；通过 `creates_remains()` 排除普通尸体和营养收益。设施未登记为任何生产批次的成员。

点击设施或目标页按钮将其设为优先目标，再次点击或使用“恢复自动选敌”取消。射程外的武器继续正常选敌，不会为了优先目标跨越射程射击。自动选敌先处理射程内的敌人，空闲时攻击设施。B放置攻击芽时显示普通攻击射程及可覆盖的AI；原有地形预览继续负责不可达和非法落点提示。

新枚举值 `SILK_GNAWER=4`、`JUNCTION_GNAWER=5` 不改变原0～3序号。两种正式啃食者分别只选择菌丝和菌结，没有同类合法目标时待机或重新搜索，不回退攻击母核或器官。第一关原 `GNAWER=3` 的混合目标行为保留。

设施图形位于 `Visuals/Factory`，可替换该视觉子树；保留设施根脚本、生命条、状态标签及出生点引用。

## 验证入口

- `tests/second_level_test.gd`：独立开局、目标面板、真实弹丸击毁设施、无额外收益、来源停产与旧敌保留、压力上限、暂停、互斥啃食目标、同帧失败优先、第一关到第二关跳转及重开。生命周期夹具会缩短生产间隔或直接造成终局伤害，不作为正常通关证据。
- `tests/second_level_playthrough_test.gd`：按左右两种顺序提交真实远程培育、付费修复及散射分化，使用原生产节奏和武器伤害完成目标，不注入营养或伤害。受损建设可按正常费用重建。自动试玩用于检查路线可行性，不能替代人工键鼠体验与平衡评估。
- 修改公共选敌、弹丸与回收后，继续运行原 `target_selection_test.gd`、`incoming_damage_test.gd`、`coordinated_combat_test.gd`、`enemy_batch_integration_test.gd` 及第一关面板与集成检查。
